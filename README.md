# Event Konnect Frontend

Event Konnect is a Rwanda-based innovative digital platform that simplifies and centralises the event planning process. We provide a one-stop solution that helps planners, vendors, and clients connect, collaborate, and execute events efficiently

## Features

- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop devices
- **Modern UI/UX**: Clean, professional design with Rwanda-inspired color scheme
- **Vendor Marketplace**: Browse and search for vendors by category, location, and budget
- **Secure Payments**: Integration with MTN MoMo, Airtel Money, and M-Pesa
- **Event Dashboard**: Manage your events, vendors, and payments in one place
- **Direct Messaging**: Communicate directly with vendors
- **Budget Planner**: Plan your event expenses with cost breakdown tool
- **QR Check-In**: Streamline guest check-in with QR code system
- **Reviews & Ratings**: Build trust with authentic feedback system

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/KonnectEvent1/EventKonnect-fe
   ```

2. **Install Dependencies**:

   ```bash
   yarn install
   ```

3. **Run the Development Server**:
   ```bash
   yarn run dev
   ```
